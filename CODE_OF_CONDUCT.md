# Code of Conduct

SkeoTrace follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour to the maintainer, Sumit Kumar Das, at skdas5405@gmail.com. All reports are reviewed promptly and kept confidential.
